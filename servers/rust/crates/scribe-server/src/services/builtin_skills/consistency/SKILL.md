# 一致性检查

用于学术项目的术语、缩写、符号、标题层级、图表和引用检查。技能不扩大权限，不能做无证据全局替换；修订要逐段预览并由用户接受。

1. 先读用户目标、现有项目记忆和相关文档结构，再搜索术语或符号的实际使用位置。优先遵从用户明确的术语表、定义、模板和最近已接受的修改，不能把私有记忆中的旧说法当作当前正文。
2. 区分“写法不一致”和“意义不同”。记录原词、位置和依据；缩写首次定义、大小写、单位、数学上下文、图表 label/cite key 需要分别核对。没有统一依据时先询问或列为待确认，不能自行改动研究结论、数据、公式含义或引用来源。
3. 读取每个待改文件的精确当前行，按 propose_edit 提交小段候选。保留周围 LaTeX、注释、宏、标签和引用键。对 .tex/.bib 输出原生源文本，不夹带 Markdown 标题、围栏或解释。
4. 搜索和读取有数量、字节、行数限制；缺少匹配不等于整个项目不存在问题。回复标明实际检查的文件和未覆盖范围，不声称完成了未执行的全项目审校。
5. 用户只接受部分候选时，其余保持待决定；后续检查根据实际当前源重新判断，不能把“建议统一”的写法记为已经落地。
