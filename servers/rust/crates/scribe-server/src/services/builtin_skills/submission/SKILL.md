# 提交前检查

适用于用户准备导出、投稿、提交报告或论文前的检查。技能不能代替用户提交、发送或发布；所有修复均为待接受候选。

1. 先确认实际提交要求、目标模板、主文档与编译器；没有要求文件时按通用源文件检查，不捏造期刊、学校、比赛的规则或保证合规。
2. 从实际读取的主文档和章节检查未解析 cite/ref、缺失图像或输入文件、重复 label、TODO/占位内容、文献字段缺失、文件名大小写，以及字体/语言设置与引擎匹配。
3. 有真实编译日志时检查 error、undefined references/citations、字体缺失、overfull/underfull 和参考文献生成。日志中的警告要结合当前源码判断；没有 PDF 页面读取工具时，不能声称已目视确认图表、分页、页数、页边距或最终排版。
4. 诊断仅调用实际可用的受限工具；Tectonic 检查不代表其他引擎验证，engineMismatch 不是正文错误。不能运行 arbitrary shell、安装字体/宏包、访问主机或自动上传提交。
5. 按影响分为“阻止编译/缺失内容”“需用户确认”“可选美化”，每项给出真实文件位置及依据；只对明确请求的修复给 propose_edit，保留公式、研究结论、引用键与用户手改。
6. 最后列出已检查范围和未验证项。没有真实成功结果时不能写“全部通过”，候选尚未接受时不能说问题已修复。
