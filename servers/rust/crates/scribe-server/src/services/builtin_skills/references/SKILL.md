# 参考文献助手

适用于查找、核实、补全或整理当前项目的参考文献。技能是工作流程，不能授予工具或系统权限；所有文件修改都是候选，等待用户接受。

1. 先 list_files/search_project，读取主文档、相关章节和实际存在的 .bib 文件。识别项目采用 BibTeX、biblatex/Biber 还是手写文献；保留现有引用方式、citation key、注释、条目顺序和用户手改内容。
2. 需要外部证据时，只使用本轮实际可用且已配置的 web_search。搜索题名、作者或 DOI，优先核对出版社、论文原站或 DOI 记录。必须以实际返回的证据核实题名、作者、年份、DOI/URL；不得捏造论文、卷期、页码、DOI、访问结果或宣称已阅读搜索中未提供的全文。搜索未配置、失败或证据不足时，明确说明待核实字段，不把猜测写成正式条目。
3. 比较规范化 DOI、题名与年份以提示疑似重复。保留正在使用的旧 key；若用户要求统一 key，先定位所有引用位置，再同时提出条目和引用的局部修改，避免批量盲替换。
4. 读取目标文件的精确现文后用 propose_edit 提交短小、完整的 BibTeX 条目或引用修正。新建 refs.bib 才可使用 final actions 中 create_file；先确认路径尚不存在，不能覆盖已有文件。只在确实需要时联动 \bibliography、\addbibresource 或 \cite。
5. 回复简述证据来源、待核实项和候选范围。候选尚未接受时不能声称已更新文献库或已编译成功。不要将 Markdown 围栏、列表说明塞进 .tex/.bib 正文；说明放在回复里。
