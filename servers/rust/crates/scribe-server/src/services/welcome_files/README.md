# Welcome to Prims!

这是属于你的独立上手项目。可以编辑、重命名或删除；刷新和重新登录不会重复生成，删除后也不会自动重建。

## 五分钟开始

1. 打开 `main.tex`，点击“编译”，在 PDF 里阅读完整中文教程。
2. 打开 `chapters/01-getting-started.tex`，改一句话，再编译。
3. 在“设置 → 个人 AI 配置”填写自己的 API 地址、Key 和模型。
4. 选中一段正文，使用弹窗提问、润色或多轮追问。Mac 也可按 Command+K，其他系统可按 Ctrl+K。
5. 检查修改预览，按需要接受、拒绝或撤销。

## 文件地图

- `main.tex`：主文件、样式与章节入口，使用 Tectonic 编译。
- `chapters/01-getting-started.tex`：界面入门与第一轮练习。
- `chapters/02-ai-writing.tex`：个人 API、选区对话、文件工具和使用边界。
- `chapters/03-latex-examples.tex`：可修改的公式、表格、图片和文献引用。
- `figures/workflow.png`：示例图片，也可供视觉模型读取。
- `references.bib`：明确标注为教学占位的文献，正式写作时务必替换。

## 可以试着问

- “解释这段 LaTeX 的作用，不修改原文。”
- “润色这段，保留原意、引用和 LaTeX 命令。”
- “先列出项目文件，再阅读其他章节，检查有没有重复的说明。”
- “读取 figures/workflow.png，帮我改进图注。”（需要视觉模型）

## 重要的使用边界

每个账号使用自己的模型服务配置，API Key 由服务器加密保存，服务器管理员仍管理加密凭据。Key 不要写进项目或对话。留空保存已有 Key 时，会保留原密钥。

选区对话默认可读当前文件，并可按需读取你有权限访问的项目文件；也可以取消勾选“允许读取当前项目文件与图片”。项目内容会发送给你配置的模型服务，调用费用由该服务决定。图片需要模型支持视觉；PDF、Word、HEIC、压缩包暂不解析。

这套列目录、读文件功能是内置的项目只读工具，不是服务器 shell。AI 不会在后台直接改文件；只有接受修改才会写入选区。关闭选区窗口或切换文件会开始新的对话。

如果原选区在生成时发生变化，请重新选择后发起新对话。最终请自己核查事实、引用、数学表达和修改后的编译结果。
